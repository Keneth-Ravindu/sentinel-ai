# Architecture Decision Records

Architecture Decision Records (ADRs) document important technical decisions made
during SentinelAI development.

Each ADR records:

- the problem,
- considered options,
- the selected decision,
- consequences,
- alternatives.

## Naming Convention

```text
0001-use-fastapi.md
0002-use-postgresql.md
0003-use-pgvector.md
0004-human-approval-for-write-tools.md
